# Security and Sensitive Data

Please do not open public issues or pull requests containing client, employer, employee, HR, legal, financial, health, confidential, regulated, proprietary, credential, API key, token, private link, or personal information.

Only submit public or synthetic examples. For sensitive corrections, contact
the maintainer through [AI Tutorium](https://aitutorium.com).

If a contribution needs an example, use synthetic data.

# Professional AI-Use Checklist

Last reviewed: 2026-07-24. See [sources and verification notes](../sources.md).

Use this before using AI for work that may affect clients, colleagues, customers, finances, legal rights, employment, security, reputation, or published output.

## 1. Aim

- [ ] I can finish: "I'm using AI because I want to ___."
- [ ] The task is suitable for AI support, not a decision that must be made by a human.
- [ ] I know whether the output is private thinking, internal work, client-facing, public, or decision-shaping.

## 2. Tool and Data

- [ ] I know whether I am using a public/personal tool or an approved work tool.
- [ ] I have checked the allowed data class for this tool.
- [ ] I have not entered confidential, client, personal, HR, legal, financial, health, regulated, security, or proprietary data into a public tool.
- [ ] I have not entered credentials, API keys, tokens, private links, or secrets.
- [ ] Connected apps, files, memory, browser access, voice, and screen access are appropriate for the task.

## 3. Brief

- [ ] I gave enough context for useful output without oversharing.
- [ ] I used placeholders, summaries, redaction, or synthetic examples where possible.
- [ ] I separated facts I know from assumptions I want AI to test.

## 4. Check

- [ ] I verified every fact, number, citation, quote, source, formula, and claim.
- [ ] I checked tone, bias, accessibility, and suitability for the audience.
- [ ] I tested code, calculations, or process steps independently.
- [ ] I removed hallucinated citations, unsupported claims, and overconfident language.

## 5. Protect

- [ ] A human owns the decision and output.
- [ ] AI has not made a price, promise, policy exception, eligibility decision, HR decision, legal/financial recommendation, or client commitment without authority.
- [ ] I disclosed AI use where required by employer, client, regulator, professional body, publisher, or policy.
- [ ] I kept a record if the work is material, client-facing, regulated, or decision-shaping.

## If Unsure

Treat unsure as no for public tools. For approved work tools, ask the tool owner, manager, DPO/data lead, legal, security, or compliance contact.
